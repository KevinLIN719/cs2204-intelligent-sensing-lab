# CS2204 Intelligent Sensing Lab Coursework

Live site: https://kevinlin719.github.io/cs2204-intelligent-sensing-lab/

Four versions of a six-page website for a fictional intelligent sensing laboratory, published as static pages. CW1 to CW3 are the coursework iterations, kept in the state in which they were developed. The AI+ edition is a single-page rewrite built from the CW3 content. The landing page links to all four.

## Contents

| Path | Description |
| --- | --- |
| `index.html` | Landing page linking the four versions |
| `cw1/` | First iteration: HTML only, no stylesheet |
| `cw2/` | Second iteration: HTML and CSS separated, layout work, print stylesheet |
| `cw3/` | Final iteration: JavaScript for the apply, visit and information pages |
| `ai-plus/` | AI-enhanced single-page edition |
| `screenshots/` | Preview images used by the landing page |

## Running locally

Open `index.html` in any modern browser. There is no build step and no dependency.

## Deployment

Published with GitHub Pages from the `main` branch, repository root. The landing page is `index.html`.

## Notes on the published copy

- CW1 has no stylesheet by design. The first assignment covered HTML structure only, so the pages render as unstyled HTML.
- `cw2/html/design.html` and `cw3/html/design.html` are the original design write-ups. The CW3 copy still refers to JavaScript not being allowed; that text belongs to the CW2 write-up and was left unchanged.
- The information page embeds four video files hosted on the course server (`personal.cs.cityu.edu.hk`). Those URLs are unchanged and depend on the course server remaining available.
- `cw3/html/visit.html` loads the booking helper script provided by the course server.
- All forms are front-end only. Nothing is submitted or stored.
- The student id printed on the original design pages has been removed from this copy.

## AI use

CW1 to CW3 are the original coursework submissions and were not generated by AI. The `ai-plus/` edition was built with AI assistance: its content is carried over from CW3, and its layout, tab routing, form validation and theme switching were produced with AI help and checked by the author. The AI+ page states this in its footer.
